# ConcreteLab — تبدیل به PWA

این پوشه نسخه‌ی Progressive Web App برنامه‌ی «مدیریت طرح اختلاط بتن» شماست.

## فایل‌ها
- `index.html` — همان برنامه‌ی شما، با افزودن لینک manifest، آیکون‌ها، meta تم، و ثبت Service Worker.
- `manifest.json` — مشخصات PWA (نام، رنگ، آیکون‌ها، حالت standalone).
- `sw.js` — Service Worker برای کارکرد آفلاین (کش کردن فایل‌های برنامه).
- `icons/` — آیکون‌های ۱۹۲ و ۵۱۲ پیکسل (معمولی و maskable) و apple-touch-icon.

## نکته‌ی مهم درباره‌ی File System Access API
برنامه‌ی شما از `showOpenFilePicker` برای اتصال مستقیم به فایل روی دیسک استفاده می‌کند. این API:
- فقط در مرورگرهای مبتنی بر Chromium (Chrome, Edge, Opera, Brave روی دسکتاپ و اندروید) کار می‌کند؛ در Safari و Firefox پشتیبانی نمی‌شود (برنامه‌ی شما ظاهراً حالت fallback هم دارد).
- به یک "secure context" نیاز دارد: یعنی باید روی `https://` یا `http://localhost` اجرا شود، نه با باز کردن مستقیم فایل با `file://‎`.

Service Worker هم دقیقاً همین محدودیت را دارد (فقط روی HTTPS یا localhost ثبت می‌شود)، پس برای تست PWA حتماً باید از یک سرور محلی یا هاست واقعی استفاده کنید.

## تست محلی
در همین پوشه یکی از این دستورها را اجرا کنید و بعد به آدرس نمایش داده‌شده بروید:

```bash
# پایتون
python3 -m http.server 8080
# یا با Node
npx serve .
```

سپس در Chrome به `http://localhost:8080` بروید. باید دکمه‌ی «نصب اپلیکیشن» را در کنار سایر دکمه‌های بالای صفحه ببینید (ممکن است چند ثانیه طول بکشد تا مرورگر شرایط نصب را تأیید کند).

## انتشار روی وب (برای استفاده‌ی واقعی)
هر هاست استاتیک با HTTPS کافی است، مثلاً:
- **GitHub Pages**: محتوای این پوشه را در یک ریپازیتوری push کنید و Pages را روی شاخه‌ی مربوطه فعال کنید.
- **Netlify / Vercel / Cloudflare Pages**: کل پوشه را drag-and-drop یا از طریق CLI دیپلوی کنید.

فقط دقت کنید مسیر فایل‌ها (`manifest.json`, `sw.js`, `icons/...`) نسبت به `index.html` همان ساختار پوشه‌ی فعلی حفظ شود.

## وقتی برنامه را ویرایش کردید
هر بار محتوای `index.html` (یا هر فایل دیگر داخل کش) را تغییر دادید، عدد نسخه در ابتدای `sw.js` را تغییر دهید:

```js
const CACHE_NAME = 'concretelab-cache-v5'; // بالا ببرید
```

## اگر لوگو یا تغییرات جدید نمایش داده نشد
Service Worker به‌صورت پیش‌فرض نسخه‌ی کش‌شده را سریع‌تر از شبکه نمایش می‌دهد. اگر بعد از یک آپدیت، هنوز نسخه‌ی قدیمی (بدون لوگو یا با گرافیک قبلی) را می‌بینید:
1. صفحه را کامل ببندید و دوباره باز کنید (رفرش ساده گاهی کافی نیست).
2. یا در Chrome: DevTools → Application → Service Workers → گزینه‌ی "Unregister"، سپس Application → Storage → "Clear site data"، و رفرش کنید.
3. اگر برنامه را قبلاً روی صفحه‌ی اصلی موبایل نصب کرده‌اید، آیکون آن روی هوم‌اسکرین جداگانه کش می‌شود و با آپدیت فایل‌ها خودبه‌خود عوض نمی‌شود — باید برنامه را حذف و دوباره نصب کنید تا آیکون جدید را بگیرد.


بدون این کار، کاربرانی که قبلاً برنامه را باز کرده‌اند ممکن است نسخه‌ی کش‌شده‌ی قدیمی را ببینند تا وقتی که Service Worker جدید به‌طور کامل فعال شود.

## آیکون‌ها
آیکون‌ها به‌صورت خودکار و هماهنگ با رنگ‌بندی برنامه (سرمه‌ای/فیروزه‌ای) ساخته شده‌اند. اگر می‌خواهید لوگوی اختصاصی خودتان را جایگزین کنید، فایل‌های زیر را با همان نام و اندازه جایگزین کنید:
- `icons/icon-192.png` (۱۹۲×۱۹۲)
- `icons/icon-512.png` (۵۱۲×۵۱۲)
- `icons/icon-maskable-192.png` و `icons/icon-maskable-512.png` (طرح باید کمی از لبه‌ها فاصله داشته باشد چون توسط سیستم‌عامل برش داده می‌شود)
- `icons/apple-touch-icon.png` (۱۸۰×۱۸۰)

## گزارش جامع (خروجی PDF)
دکمه‌ی «📄 گزارش جامع (PDF)» در بالای صفحه، یک نمای چاپی کامل از همه‌ی طرح‌های اختلاط، نمونه‌ها، نمودارها، و ارزیابی مطابقت ACI 318/214 می‌سازد و پنجره‌ی چاپ مرورگر را باز می‌کند.
برای ذخیره‌ی آن به‌صورت PDF: در پنجره‌ی چاپ، گزینه‌ی مقصد (Destination) را روی **«Save as PDF»** بگذارید و چاپ/ذخیره کنید. این روش (به‌جای یک کتابخانه‌ی جداگانه‌ی تولید PDF) عمداً انتخاب شده چون متن فارسی را دقیقاً همان‌طور که در مرورگر می‌بینید (بدون به‌هم‌ریختگی حروف) در PDF نهایی نگه می‌دارد، و به هیچ فایل/کتابخانه‌ی اضافه‌ای نیاز ندارد.
